# IPL Analytics Dashboard Using Power BI

## Project Overview
This project analyzes IPL cricket data using Power BI dashboards and visualizations.

## Features
- Overview Dashboard
- Batting Analysis
- Bowling & Fielding Analysis
- Toss Decision Analysis
- Venue Insights
- Interactive Slicers

## Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization

## Key Insights
- Most successful IPL teams
- Top batsmen and bowlers
- Toss impact on matches
- Venue-wise team performance
